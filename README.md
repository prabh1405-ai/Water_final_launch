# Water Can Accounts

A daily ledger for water-can deliveries, payments, customer balances, and
operating expenses.

## Development

Requires Node.js and npm.

```sh
npm install
npm run dev
```

## Supabase and Vercel

See [`supabase/DEPLOYMENT.md`](./supabase/DEPLOYMENT.md) for private Supabase
schema setup, authentication, environment variables, and Vercel deployment.
